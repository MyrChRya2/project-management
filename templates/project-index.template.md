## 五、文档协作工作流（当前约定）

1. **决策** → 先写进当日 devlog，再同步 ROADMAP / GDD
2. **开发前** → 看 ROADMAP 优先级表
3. **设计疑问** → 查 GDD 待决策清单
4. **每日收尾** → 说"今天任务已结束"，AI 读 TEMPLATE.md 生成日志
5. **路径/结构变更** → 必须同步更新本文件
6. **周期性任务** → 记录在 ROADMAP（如周更视频/周报）
